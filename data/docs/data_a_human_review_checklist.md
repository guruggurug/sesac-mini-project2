# Data A 사람 검토 체크리스트

## 목적

자동 테스트로 사실 여부를 확정할 수 없는 공식자료 해석과 사용자 안내 문구만 Data A가 검토한다. 스키마 문법, 상태 전이, 숫자 계산, 중복 차단, severity 재현성은 자동 테스트가 담당한다.

검토 결과는 각 항목의 `승인` 또는 `수정 필요` 중 하나를 선택하고, 수정이 필요하면 제안 문구나 공식 근거를 함께 남긴다.

## 1. G01~G03 공식자료 검토

> 2026-07-25 갱신: 2026-07-24~25 원문 재대조 작업(`progress/DATA-A.md` DATA-A-06)으로 아래 표가 옛 72/78행 구조(양사 전부 `unavailable` 18행, 2022~2024 가정)에서 실측 64행 구조로 바뀌었습니다. G01·G03은 삼성전자만 실제 원문 수치를 확보했고, SK하이닉스 G01·G03과 양사 G02는 여전히 미확보 상태이되 이제는 "임시 unavailable 행"이 아니라 **행 자체가 없는 상태**로 정직하게 표현됩니다.

### 확인 방법

- [x] 회사 지속가능경영보고서, 사업보고서, DART 공시 또는 정부기관 원문인지 확인한다. — 삼성 G01/G03 3행은 지속가능경영보고서 원문(페이지 명시) 및 PIPC 의결서로 확인 완료
- [x] 문서의 회사명과 대상 기간이 CSV의 회사·기간과 일치하는지 확인한다.
- [x] 삼성전자 DS·반도체 범위인지, 연결 기준 전체 회사 범위인지 확인한다. — G01/G03은 이사회·법인 단위 지표라 `business_scope=consolidated`(스키마 규칙상 `scope_mismatch=true`)로 처리
- [x] 표의 값과 단위를 그대로 기록하고 계산값이면 계산 근거를 남긴다. — G03의 복합 텍스트(시정명령+과징금+과태료)는 raw_value를 건수(1)로 인코딩하고 원문 금액은 note에 그대로 보존
- [x] 원문 파일, 페이지, URL, SHA-256, 수집일을 source registry에 기록한다. — `sources.csv` SRC-0010(PIPC), SRC-0011/0012(삼성 2025/2026 보고서) 참고
- [x] 자료가 없거나 의미가 모호하면 값을 추정하지 않고 `raw_value=null`, `availability=unavailable`을 유지한다. — SK G01/G03, 양사 G02는 행 자체를 만들지 않는 방식으로 결측을 표현(허구 수치·임시 접수번호 사용 금지)

### 완료 판정

- [x] 승인 — 삼성 G01(2행)·G03(1행) 총 3행은 원문 페이지·URL·SHA-256까지 확인된 공식 근거를 확보했다. SK하이닉스 G01·G03과 양사 G02는 미확보 사유(보고서 범위 밖/DART 위임)가 명확하며 값을 추정하지 않았다.
- [ ] 수정 필요 — 아래에 부족한 회사·지표·기간과 필요한 자료를 적는다.
