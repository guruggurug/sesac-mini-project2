# Data A 사람 검토 체크리스트

## 목적

자동 테스트로 사실 여부를 확정할 수 없는 공식자료 해석과 사용자 안내 문구만 Data A가 검토한다. 스키마 문법, 상태 전이, 숫자 계산, 중복 차단, severity 재현성은 자동 테스트가 담당한다.

검토 결과는 각 항목의 `승인` 또는 `수정 필요` 중 하나를 선택하고, 수정이 필요하면 제안 문구나 공식 근거를 함께 남긴다.

## 2. 비전공자용 사용자 문구 검토

각 문구가 아래 세 질문을 만족하는지 확인한다.

1. 지금 어떤 상태인지 한 번에 이해되는가?
2. 사용자가 해야 할 행동이 명확한가?
3. 실제보다 최신이거나 정확한 데이터라고 오해하게 만들지 않는가?
