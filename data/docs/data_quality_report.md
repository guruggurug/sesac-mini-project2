## 4. 잔여 데이터 한계 및 위험 요인

1. **삼성전자 범위 불일치**:
   - 공급망 실사, 정보보호, 지배구조 지표에서 삼성전자는 전사 수치를 사용하여 반도체 부문 단독 수치인 SK하이닉스와의 직접 비교 시 한계가 존재합니다.
2. **용수 재이용률 산식 차이**:
   - 삼성전자는 분모를 '총 취수량'으로 두고 재이용률을 산정하는 반면, SK하이닉스는 '총 사용량(취수량+재이용량)'을 분모로 두어 산식 상의 차이가 존재합니다. (`data/docs/indicator_comparability.csv` 참조)

## 5. 데이터 B 및 백엔드 팀을 위한 최종 전달 메모

1. **지수 및 가격 파일 위치**: `data/processed/stock_prices.csv`와 `data/processed/index_prices.csv`를 단일 자동 검증 파일로 사용해야 합니다.
2. **사건 반응 분석 기준일**: 주가 반응 분석(사건 전후 1·3·5일 초과수익률) 시 발생일이 아닌 **`market_event_date`**를 기준으로 삼아야 합니다.
3. **결측 대체 금지**: 수치 항목이 `unavailable`인 경우, 임의로 0이나 평균값으로 대체해서는 안 되며 UI 단에서 데이터 부족으로 명시해야 합니다.
4. **이슈 계약 준수**: 후보·출처·중복·severity 판정은 `schemas/data/issue-pipeline-rules.json`과 `data/docs/issue_pipeline_contract.md`를 기준으로 하며, 규칙 버전 변경 시 processed 사건 전체를 재산정해야 합니다.
